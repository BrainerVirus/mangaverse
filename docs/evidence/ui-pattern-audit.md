# UI pattern audit

Measured 2026-11-06 at `2238f9e3` (origin/main), branch `chore/ui-pattern-audit`. Scope: every `.tsx` under `apps/web/app`, `apps/desktop/src/renderer`, `packages/design-system`, `packages/reader`, `packages/extensions`, `packages/cache` (non-test), plus the `*-variants.ts` class maps. Method: ripgrep scans, the `ui-conventions` oxlint plugin run over the whole tree with every rule on, a Tailwind compile of the app stylesheet to read what a class resolves to, and a read of the primitives and the highest-count files. Loading-state work is another agent's; overlaps are marked **(loading)**.

What was already clean, by scan: no hex, `rgb()`, `hsl()` or palette colour in any `className` or `style` outside `apps/web/app/features/theme` (theme data, by design); no arbitrary `[...]` value in any `.tsx`; no `backdrop-*` or `bg-white/N`, `bg-black/N` outside the reader stage; no `Card` or `SettingsSection` nested in the same file; no `border` beside a resting `ring`; no deep `@app/design-system/*` import from a feature (the package `exports` map allows only `.`, `./motion` and the stylesheet). `@shadcn/lint` is already at `error` for all six rules.

## Rules

See AGENTS.md "UI Pattern Rules". `lint/ui-conventions.cjs` has 11 rules; 3 are enforced at zero (`no-nested-card`, `no-hand-rolled-glass`, `no-border-ring-doubling`) and 8 are frozen per file in `lint/ui-baseline.json`: 129 sites in 39 files (panel 43, size 31, heading 24, radius 18, hover/focus 6, variant-map 5, shadow 1, gsap 1). Fixing a site lowers the count: `pnpm lint:ui-baseline --shrink`.

Rejected, with evidence:

- `outline-none` without a replacement ring: 4 sites on the tree, all legitimate (`AppShellLayout.tsx:60` is a `tabIndex={-1}` skip-link target, `ui/select.tsx:138` shows focus as `focus:bg-accent`, `ui/dialog.tsx:23` is the dialog container, `ui/command.tsx:24` is item 23). A rule would need all four exempted.
- `border` plus `focus-visible:ring-*`: the shadcn focus pattern on Input, Select and Tabs (19 `focus-visible:ring-2` sites in all).
- `text-sm`/`text-xs` against `type-*`: DESIGN.md §4 keeps `text-sm` as the components' convention and the palette group header stays `text-xs`; the heading subset is enforced instead.
- Cross-file card nesting: needs a rendered tree. None found by reading the 14 files that use `Card`/`SettingsSection`; `BulkEditBar` (item 2) is the only panel-around-card case.
- `useState` outside the URL, route, store: already enforced by `team-conventions/no-use-state` with `lint/baseline.json` (140 uses in 52 files, plus 114 `try/catch` in 54); a lint rule cannot tell state that belongs in the URL from state that does not.
